إعدادات الموجهة

الربط يتم على هاتف الزوجة بحسابها هي.

اتصال Google

يُستخدم معرّف عميل Google Cloud المسموح له بالعمل من عنوان الموقع هذا. حفظه على الهاتف لا يمنح أحدًا صلاحية الوصول إلى الملفات.

غير متصل

مجلد درايف الرئيسي

يتم إنشاؤه مرة واحدة باسم «شواهد برامج التوجيه الطلابي» في حساب الزوجة ويُضبط للمشاهدة العامة. المجلد القديم لا يُمس.

هوية أكواد QR

الشعار الافتراضي كحلي وذهبي. يمكن رفع أيقونة مربعة خاصة، وسيظهر تغييرها في كل الأكواد الجديدة دون تغيير روابطها.

إعداد Google Cloud مرة واحدة

  1. أنشئ مشروعًا في Google Cloud Console وفعّل Google Drive API.
  2. من Google Auth Platform اضبط شاشة الموافقة، وأنشئ OAuth Client ID بنوع Web application.
  3. أضف نطاق JavaScript المصرّح به: https://drburghash-sys.github.io.
  4. أضف بريد الزوجة ضمن Test users إذا كان التطبيق بحالة الاختبار، ثم انسخ Client ID أعلاه.
  5. زوجتك تسجل بحسابها، ثم تضغط إنشاء / استعادة المجلد.

لا تضعي Client Secret أو مفتاح API خاصًا أو كلمة المرور في الموقع. إذا رفض حساب مدرسي المشاركة العامة فقد تكون سياسة المشرف تمنعها.

الأمان

الموقع عام، لكن عمليات التعديل تحتاج تصريح Google على حساب مالك الملفات. مشاركة QR تمنح «مشاهدة فقط». تأكدي من إخفاء البيانات الشخصية للطالبات في الشواهد العامة.
